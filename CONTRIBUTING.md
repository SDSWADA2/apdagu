# CONTRIBUTING

Terima kasih atas minat Anda berkontribusi pada proyek ini.

Panduan singkat:

1. Fork repository ini dan buat branch fitur/bugfix dari branch default.
2. Jalankan linters dan tests sebelum membuat PR.
3. Buka PR ke branch default dan jelaskan perubahan serta testing yang dilakukan.
4. Semua PR akan menjalankan CI: lint → audit → test.

Kode harus menggunakan gaya yang konsisten. Gunakan ESLint yang disediakan.
